## Caption
Got a spring marathon booked? Count 16 weeks back from race day: that Monday is when your training starts, and for some of these it's before Christmas.

Here's all 8, with the date, the Monday your 16 weeks start, and when your longest run lands (about 3 weeks out).

S tier, Seville: Sunday 21 February. The flattest course in Europe. Your 16 weeks started on Monday 2 November; longest run about 31 January. Sold out (waiting list only).

A tier, Manchester: Sunday 18 April. About 54 metres of climbing. Start Monday 28 December; longest run about 28 March. Sold out.

B tier, Barcelona: Sunday 14 March. Long straight roads, more of the climbing in the first half. Start Monday 23 November; longest run about 21 February. Still open.

B tier, Paris: Sunday 4 April. Rolling, with short tunnel dips by the Seine. Start Monday 14 December; longest run about 14 March. Sold out.

B tier, London: Saturday 24 or Sunday 25 April (two days in 2027). Crowded once the starts merge. Start Monday 4 January; longest run about 4 April. Ballot closed, charity places only.

C tier, Rome: Sunday 14 March. About 6K of cobbles. Start Monday 23 November; longest run about 21 February. Still open.

C tier, Brighton: Sunday 4 April. Short, sharp climbs, most done by 18K. Start Monday 14 December; longest run about 14 March. General entry sold out, charity places.

D tier, Belfast: Sunday 2 May. Short, sharp hills and wind off the Lough. Start Monday 11 January; longest run about 11 April. Still open.
