# Research

Raw transcripts/notes Luke uploaded, kept here in full so
`principles.md` and `hook-frameworks.md` (which distill and cite this
material) can be checked against the source, and so future work can
mine detail that didn't make it into the distilled versions.

- `briar-cochran-notes-accordion-tam-ccn.txt` — Briar Cochran notes:
  the 3-part perfect-video check (TAM/angle/money), the Accordion
  Method, MVC/content market fit, niche vocabulary ("iceberg"),
  on-screen text copywriting, progressive intrigue, counter
  positioning.
- `briar-cochran-hook-titles-and-swipefile.txt` — screenshot-derived
  list of Briar Cochran video titles (useful as a topic/format
  reference), plus swipe examples from other creators
  (@christian.j.lynch, @brandon_trajano) and the 30-item fill-in-blank
  hook template list.
- `briar-cochran-counter-positioning.txt` — standalone transcript
  fragment of the 3 counter-positioning tactics (duplicate of a
  section in the notes file above, kept as its own doc since it was
  uploaded separately).
- `heaton-ralston-personal-brand.txt` — "content that gets you
  customers" 6-point list, plus a separate personal-brand philosophy
  segment (foundation-first, curated partnerships, stay true to
  yourself).
- `paddy-galloway-ccn-interview-transcript.txt` — full podcast
  interview with Paddy Galloway (YouTube strategist): CCN framework,
  outlier definition and reflection prompts, idea funnel, view
  maximizer vs. targeted views, packaging/thumbnail principles,
  channel growth phases (establishment / improvement / optimization).

See `principles.md` and `hook-frameworks.md` at the repo root for the
distilled, numbered (P1-P14, HF1-HF8) versions these skills actually
cite.
